# Badge

Badge labels a status or category with a short word, in a pill.

- **Provide:** `tone` and a one- to three-word label as children.
- Status tones (`success`, `warning`, `danger`, `info`) always show their icon. Status is never shown by color alone: color, icon and word together.
- `brand` uses the scoped product's tint and primary, for categories such as "New" or "Founding member".
- `neutral` is for counts and metadata ("12 volunteers").
- Labels are sentence case and describe state, not action: "Overdue", "Confirmed", "2 spots open".
